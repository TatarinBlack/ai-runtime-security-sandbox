# Product FAQ

**What is Nova Cloud Guard?**
Nova Cloud Guard is a cloud security posture management platform that
detects misconfigurations across Azure and AWS environments and offers
automated remediation suggestions.

**Which cloud providers do you support?**
Microsoft Azure, Amazon Web Services, and Google Cloud Platform are fully
supported today. A separate module is available for Kubernetes environments.

**What are your support hours?**
Enterprise customers receive 24/7 support. Standard plan customers can reach
support Monday to Friday, 09:00-18:00. The SLA for critical incidents is 1
hour.

**How does pricing work?**
Pricing depends on the number of monitored resources and the selected plan.
Contact the sales team for the current price list.
